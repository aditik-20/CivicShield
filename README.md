# CivicShield


## Project Overview
Analysis and machine learning of urban accident patterns
using traffic, temporal and geographical information.

## Objectives
- Analyze accident patterns
- Perform exploratory data analysis
- Study accident severity
- Model hourly accident counts
- Classify accident severity

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning

### Regression
Polynomial Regression

### Classification
- Logistic Regression
- Linear SVM

## Results

| Model | Accuracy | Serious Recall | Serious F1 |
|---|---:|---:|---:|
| Logistic Regression | 54.31% | 50.53% | 30.91% |
| Linear SVM | 53.93% | 52.02% | 31.35% |
